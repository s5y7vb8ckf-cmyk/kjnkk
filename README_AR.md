# Ford Drive Lite — K2001N

نسخة اختبار مخصصة لشاشة K2001N، أندرويد 10، ذاكرة 1GB.

## ما يعمل في المصدر
- واجهة أندرويد أصلية دون WebView، وصورة سيارة WebP شفافة ثابتة.
- ساعة وتاريخ يتحدثان كل دقيقة أثناء ظهور التطبيق فقط.
- قائمة التطبيقات المثبتة وفتحها.
- اختصار الملاحة، الموسيقى، إعدادات الشبكة والبلوتوث.
- التسجيل كتطبيق HOME مع فتح إعدادات اختيار المشغل، إذا كان الجهاز يسمح بذلك.

## البناء
ارفع محتويات ZIP (وليس ZIP نفسه) إلى مستودع GitHub جديد، ثم Actions > Build Ford Drive Lite APK > Run workflow. نزّل Artifact بعد نجاح البناء.

## أمان وتجربة
لا تختَر التطبيق كواجهة افتراضية حتى تختبره كتطبيق عادي وتتحقق من عمل الرجوع والموسيقى والراديو والكاميرا. لم يُبنَ APK أو يُختبر على شاشة فعلية في هذه البيئة. الإصدار التجريبي غير موقّع بتوقيع إنتاج. لا تحذف مشغل المصنع.

## ملاحظة
اسم الحزمة مختلف عن الإصدارات السابقة للسماح باختبار النسخة الجديدة دون استبدال القديمة.
